Testing-Tools
=============

Default repo for PC bench tools used with Crestron-Modules.

Install (once)
  1. Python 3.9+ from python.org  — check "Add python.exe to PATH"
  2. Double-click install-dependencies.bat  (needed for SSH)
  3. Right-click allow-firewall.bat → Run as administrator (once)

TCP Client (Dynamic IP)  — processor connects to this PC
  1. Double-click start-tcp-server.bat
  2. Set Address$ = LAN IP printed by the server (not 127.0.0.1)
     Port = 23
  3. Hold Connect
  4. Type here to send; [RX] is data from the processor

SSH Client  — processor connects to this PC over SSH
  1. Double-click start-ssh-server.bat
  2. Set Client module:
       IP_Address$ = LAN IP printed by the server (not 127.0.0.1)
       IP_Port     = 2222
       Username$   = crestron
       Password$   = crestron
       Accept_Any_Key = Yes
  3. Hold Connect

Inbound TCP on the processor (built-in TCP/IP Server)
  1. Add TCP/IP Server in Configure view. IP-NET Address = 0.0.0.0 (blank will not listen)
  2. Hold Enable high, note the Port parameter (e.g. 5000)
  3. Double-click start-tcp-client.bat
  4. Enter processor IP and that port
     Connection refused = processor is up but not listening — Enable / port / IP-NET, not this script.

TCP Server with Authentication
  1. Double-click start-tcp-auth-client.bat
  2. Enter processor IP, port (default 50001), optional TLS / AUTH

Remote File Sync  — processor connects to this PC
  1. Double-click install-dependencies.bat once (HTTP, HTTPS, and FTP)
  2. Right-click allow-firewall.bat → Run as administrator (once; includes 8080, 8443, 2121)
  3. Double-click start-remote-file-sync.bat
  4. Remote_URL examples, using the LAN IP the window prints:
       http://<LAN IP>:8080/present.json
       https://<LAN IP>:8443/present.json   Allow_Insecure_TLS = high
       ftp://<LAN IP>:2121/present.json
     Local_Path = /user/present.json
     User and password empty, or crestron / crestron
  5. missing.json is absent. large.bin is 300 KB and must be refused.
     Type reset to restore the folder. Type list to see sizes.

UDP / UDP Broadcast
  1. Hold Enable high on the processor UDP symbol, note the port (e.g. 50001)
  2. Right-click allow-firewall.bat → Run as administrator (once; includes UDP 50001)
  3. Double-click start-udp.bat
  4. Port = 50001
     Send to = 255.255.255.255 (broadcast) or the processor IP (unicast)
  5. Type here to send; [RX] is datagrams from the LAN

UDP Census (one RMC4 is enough)
  1. Use UDP Census v1.0. Leave the v2 beacon off. Both want port 50001.
  2. Right-click allow-firewall.bat → Run as administrator (once; includes UDP 50001)
  3. Double-click start-udp-census.bat. Do not also run start-udp.bat.
  4. Collector: Census_Enable and Census_Discover high. This PC appears as pc-1.
     peers 2 adds a second fake processor on the next poll.
  5. Answer-only: Census_Enable high, Census_Discover low. Type poll here.
