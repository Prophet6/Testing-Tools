Testing-Tools
=============

Default repo for PC bench tools used with Crestron-Modules.

Install (once)
  1. Python 3.9+ from python.org  — check "Add python.exe to PATH"
  2. Double-click install-dependencies.bat  (needed for SSH)
  3. Right-click allow-firewall.bat → Run as administrator (once)

TCP Client (Dynamic IP)  — processor connects to this PC
  1. Double-click start-tcp-server.bat
  2. Set Address$ = LAN IP printed by the server (not 127.0.0.1)
     Port = 23
  3. Hold Connect
  4. Type here to send; [RX] is data from the processor

SSH Client  — processor connects to this PC over SSH
  1. Double-click start-ssh-server.bat
  2. Set Client module:
       IP_Address$ = LAN IP printed by the server (not 127.0.0.1)
       IP_Port     = 2222
       Username$   = crestron
       Password$   = crestron
       Accept_Any_Key = Yes
  3. Hold Connect

Inbound TCP on the processor (built-in TCP/IP Server)
  1. Enable TCP/IP Server in SIMPL, note its port (e.g. 5000)
  2. Double-click start-tcp-client.bat
  3. Enter processor IP and that port

TCP Server with Authentication
  1. Double-click start-tcp-auth-client.bat
  2. Enter processor IP, port (default 50001), optional TLS / AUTH

Other
  rotate-host-key.bat     new SSH fingerprint (Accept_New_Key test)
